Industrial relocation scorecard - reusable client presentation tool

Recommended format
- Use the HTML dashboard as the working presentation tool.
- Save one exported JSON file per client or pursuit.
- Re-import the JSON file to revise the same client presentation later.
- Export CSV when you need the scoring table for PowerPoint, Excel, or backup analysis.

How to use
1. Open industrial_tenant_scorecard.html in Chrome or Edge.
2. Click Criteria and weights to customize the client decision factors.
3. Click Add building and enter each option.
4. Click Find coordinates after entering an address, or manually paste latitude and longitude.
5. Use Executive scorecard for the client-facing map and ranked option list.
6. Export client file to save the full setup as JSON.

Map notes
- The basemap is Esri World Imagery.
- State and county lines are loaded from a public TopoJSON layer.
- Address geocoding uses OpenStreetMap Nominatim from the browser.
- For confidential work or if geocoding is blocked, paste lat/lng manually from Google Maps or CoStar.

Best practice
- Keep 8 to 12 weighted criteria.
- Split criteria between quantitative and qualitative issues.
- Use the score as a discussion framework, not as a mechanical recommendation.
- Customize weights by client: ecommerce, food, 3PL, manufacturing, cold storage, port users, HQ/office-heavy industrial, etc.
